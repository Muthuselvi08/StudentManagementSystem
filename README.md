# Student Management System – MySQL

## Project Overview
The Student Management System is a relational database project developed using MySQL to manage student and course records efficiently.

It demonstrates database design, SQL queries, CRUD operations, and relationships between tables.

## Features
- Create and manage student records.
- Manage course records.
- Perform CRUD operations (Create, Read, Update, Delete).
- Retrieve related information using JOIN queries.
- Maintain data integrity using Primary Keys and Foreign Keys.
- Apply database constraints.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## Database Concepts Covered
- DDL (Data Definition Language)
- DML (Data Manipulation Language)
- SELECT queries
- WHERE clause
- JOIN operations
- Primary Key and Foreign Key
- Database Constraints
- CRUD Operations

## How to Run
1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench.
3. Open the `StudentManagementSystem.sql` file.
4. Execute the SQL script.
5. Explore the database tables and execute the queries.
